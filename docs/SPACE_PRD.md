# FideTV Space - PRD

## Overview
A modern, real-time video conferencing platform built for instant meetings without accounts.

## Core Features
- Instant Meeting Creation
- Guest Join (DisplayName only)
- Real-time Audio/Video with WebRTC
- Screen Sharing
- Chat Functionality
- Raise Hand Interaction
- Participant Management
- Responsive Design

## User Experience
- Futuristic, Dark-themed interface
- Minimalist navigation
- Fluid animations
